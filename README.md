# Strand

An Android sleep companion for seeing a night as more than one number. Connect a sleep source and Strand gathers the recorded sessions into a daily picture, with missing measurements left clearly missing rather than filled in with guesses.

## Read the night

Home puts actual sleep beside time in bed, bedtime and wake time. It breaks recorded sleep into deep, REM and light stages, shows awake time, and includes overnight heart-rate or blood-oxygen readings when the source provides them. The distinction matters: time spent in bed is not the same as time asleep.

Insights lets you look across the last week, month, three months or all available history. It brings nights together into trends and compares adjacent periods of equal length, so a good-looking average does not quietly hide how much the pattern has shifted.

## Keep the stories too

Dreams is a journal for writing down what you remember. Each entry is saved before you request a reading; when one arrives, it is kept with that entry. If the connection fails, the writing remains and you can try the reading again.

Sleep can also be shared with friends you choose to connect with. Find someone by email, exchange a request, then compare a shared night: a timeline of both sleep stages, differences between the night summaries and a sync score. If either person has not shared that night, Strand says so instead of inventing a comparison.
